# 打赏收款码放置目录

把以下图片放到本目录（文件名固定）：

- `wechat.png` —— 微信收款码

- `alipay.png` —— 支付宝收款码

- `afdian.png` —— 爱发电二维码（可选）

放置后 README 与专题页的打赏区块自动显示（当前显示占位提示）。

## 爱发电（推荐国内用户）

1. 到 <https://afdian.com> 注册并创建页面（可设“一杯咖啡 ¥10”档位）
2. 把你的爱发电主页地址填到 README 打赏区块与专题页 Donate 区块中（搜索 `afdian.com/your-id` 替换）
3. 爱发电支持微信/支付宝收款与月度赞助，适合开源工具作者
